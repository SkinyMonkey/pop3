<objective>
Close the AI save/load gap: QuickSave currently writes `Vec::new()` for AI script variables and EVERY counters instead of extracting real state from AiSystem. QuickLoad ignores these fields entirely. This means EVERY block timing resets after load, causing AI behavior to desync.

Purpose: Without this, saving and loading a game resets all AI script progress. EVERY counters go back to 0, causing AI tribes to suddenly fire all pending EVERY blocks simultaneously on the first tick after load.

Output: AI script state (variables + EVERY counters) survives save/load round-trips.
</objective>
